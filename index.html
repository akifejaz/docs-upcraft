Features

Built to disappear into Upwork

Not a dashboard you have to visit. A layer on the page you already use.

Ten real filters

Age, proposals, payment type, experience, spend, rating, hire rate, jobs posted, client type and payment-verified — combined, applied instantly.

No page reloads

Proposal bands are read straight off the card, so narrowing your search never throws away the results you already loaded.

Keeps up with scrolling

Infinite scroll, sorting, pagination and in-page navigation are all tracked — new jobs get enriched as they appear.

Native by design

Chips reuse Upwork's own badge component, so they inherit its light and dark themes rather than approximating them.

Off means off

One switch stops the chips and the network requests behind them. No quiet background fetching.

Remembers you

Filters, panel position and preferences persist. Press Enter anywhere in the panel to apply.

Install

Running in about a minute

Load it unpacked while the Web Store listing is in progress.

Download & unzip

Grab the latest .zip from Releases and extract it to a folder you'll keep.

Load unpacked

Open chrome://extensions, switch on Developer mode, then choose Load unpacked and select that folder.

Open a search

Go to any Upwork job search and click the Upcraft icon. Chips fill in as cards scroll into view.
